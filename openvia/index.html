What does OpenVia do?

OpenVia routes links to the browser you choose. Set it as your default browser, add a few rules, and links opened from other apps go to the matching browser.

How do the rules work?

Match an exact domain, use wildcards for URLs or subdomains, or write a regular expression. You can also match HTTP or HTTPS links. Rules are checked from top to bottom, so put specific rules first.

What if a link doesn’t match?

Choose a fallback browser for everything else. OpenVia can use the system default, with Safari as a safe fallback when OpenVia itself is the default.

Does anything leave my Mac?

OpenVia stores its routing rules locally on your Mac. It passes each link to your chosen browser, which then opens the website as usual.

Where can I get it?

Download OpenVia for macOS from the v1.0.0 release on GitHub.
